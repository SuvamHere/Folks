## About Folks – A Python Typing Game

Folks is a typing game developed entirely using Python. I have tried to recreate the experience of one of the most popular typing games, **Monkeytype**.

I aimed to make the game as user-friendly and visually appealing as possible, despite it being a text-based project. I added a few predefined sentences that serve as target sentences for the game. Just like Monkeytype, users have to type the given sentences as quickly and accurately as possible. The main goal is to beat their personal typing records.

I decided to keep things simple by using Python's built-in `input()` function instead of going for more advanced approaches like the `keyboard` library. Since this is one of my rookie projects, I wanted to stick with something simple and easy for me to understand.

While developing this game, I also learned something new: how to use the **Colorama** library to add colors to text and make the overall interface look more stylish.

*The name "Folks" was chosen simply because of the event's name and has no particular connection to the actual game.*
